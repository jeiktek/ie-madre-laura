## Concepto

Una web para un colegio multi-página con estética moderna e institucional, con un toque de personalidad
pero profesional. El gancho es que se siente acogedor, llamativo y profesional, no algo genérico

## Stack y restricciones (IMPORTANTES)

- HTML + CSS + JavaScript vanilla + Lucide icons. Vite como servidor de desarrollo, nada más.
- Debe funcionar sin backend y sin build de producción complejo.
- Accesible: HTML semántico, contraste correcto (WCAG AA).

## Implementaciones

- Tema oscuro/claro con conmutador, y q respete:
- Micro-interacciones sobrias: aparición al hacer scroll, efectos en las páginas
- Rediseña los colores si amerita

## Criterios de aceptación

- Arranca con `npm run dev` sin errores
- Permite descargar y ver pdfs, gráficas claras, legibles y profesionales
- Pasa revisión básica de accesibilidad
